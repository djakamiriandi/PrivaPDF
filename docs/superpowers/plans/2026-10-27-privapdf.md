# PrivaPDF Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build PrivaPDF, a modern, privacy-first, 100% client-side offline PDF and Office document converter and manipulation web application with zero network telemetry.

**Architecture:** Single Page Application (SPA) built with React, TypeScript, and Vite. All conversions execute strictly inside browser memory using client-side binary libraries (`pdf-lib`, `xlsx`, `jspdf`, `mammoth`, `docx`, `pdfjs-dist`, `jszip`). Outbound network access is programmatically forbidden by a strict Content Security Policy (`connect-src 'none'`).

**Tech Stack:** React 18+, TypeScript 5+, Vite, Tailwind CSS, Lucide Icons, pdf-lib, xlsx (SheetJS), jspdf, jspdf-autotable, mammoth, docx, pdfjs-dist, jszip.

## Global Constraints

- **Project Location:** `/Users/jakamiriandi/Desktop/PrivaPDF`
- **Zero Network Egress:** CSP MUST enforce `connect-src 'none'`. No runtime fetch, XHR, or analytics to any external endpoint.
- **In-Memory Lifecycle:** Files must never persist on a server; blobs must be cleaned via `URL.revokeObjectURL()` immediately after download.
- **Dependency Isolation:** All scripts and styling must be locally bundled; no external CDN links in `index.html`.
- **Operating Environment:** Runs on standard modern desktop browsers (Chrome, Safari, Edge, Firefox) completely offline.
